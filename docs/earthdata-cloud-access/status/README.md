# Remote open: status and Jira comments

Project records for the SeaDAS Earthdata Cloud "Open Remotely" work. The investigation that led to it is in
[`../INVESTIGATION.md`](../INVESTIGATION.md).

| File | What it is |
| --- | --- |
| [`STATUS.md`](STATUS.md) | Copy of the status page: what works, timings, gaps, branches and open items. The [live page](https://claude.ai/artifact/UcaxyUpB23uGYC2nwWDCXt) may be newer. |
| [`jira-comments/`](jira-comments/) | Comments posted to the Jira ticket, one file per comment, named by date. |

To add a Jira comment, save it as `jira-comments/YYYY-MM-DD-<topic>.md`. To refresh `STATUS.md`, export the
live page as Markdown and keep the note under the title.
